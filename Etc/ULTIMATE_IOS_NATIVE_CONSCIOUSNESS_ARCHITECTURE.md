## 🧬 THE JAVASCRIPT WIDGET ENGINE

### How Custom Widgets Work

```javascript
// User: "I want to track my caffeine intake"
// Backend: /api/interface/orchestrate
// Gemini generates widget definition:

const widgetDefinition = {
  id: "caffeine-tracker-789",
  name: "Caffeine Tracker",
  icon: "☕",
  color: "#8B4513",

  // Widget UI (rendered by JavaScriptCore)
  renderFunction: `
    function render(data) {
      const today = data.entries.filter(e => isToday(e.timestamp));
      const total = today.reduce((sum, e) => sum + e.amount, 0);

      return {
        type: "stat_card",
        title: "Caffeine Today",
        value: total + "mg",
        subtitle: today.length + " drinks",
        progress: total / 400, // 400mg daily limit
        color: total > 400 ? "red" : "green"
      };
    }
  `,

  // Actions
  actions: [
    {
      name: "Log Coffee",
      icon: "☕",
      handler: "logEntry",
      params: { amount: 95, type: "coffee" }
    },
    {
      name: "Log Energy Drink",
      icon: "⚡",
      handler: "logEntry",
      params: { amount: 160, type: "energy_drink" }
    }
  ],

  // Backend integration
  endpoints: {
    log: "/api/custom-tracker/caffeine-tracker-789/log",
    history: "/api/custom-tracker/caffeine-tracker-789/history",
    stats: "/api/custom-tracker/caffeine-tracker-789/stats"
  }
};

// iOS renders this with:
// - WidgetKit (home screen)
// - JavaScriptCore (executes render function)
// - AppIntents (creates Siri shortcuts automatically)
```

**Result:** User can say "Log coffee" to Siri, and it logs 95mg caffeine
