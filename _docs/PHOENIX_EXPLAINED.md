## For The College Student / Developer

### What Is It?
Phoenix is a full-stack AI life operating system with 4 consciousness modules:

1. **Self-Awareness** (`selfAwareness.js` - 1,249 lines)
   - Parses all route files on startup
   - Knows every endpoint, capability, and limitation
   - Real-time health monitoring (memory, uptime, cache)

2. **Self-Correction** (`selfCorrection.js` - 1,562 lines)
   - 8 error detection patterns (stale cache, percentage overflow, metric contradiction, etc.)
   - Catches mistakes before response is sent
   - Logs corrections for permanent learning

3. **Real-Time Learning** (`realTimeLearning.js` - 1,235 lines)
   - Logs every interaction with outcome

   - Calibrates confidence without retraining

4. **Meta-Cognition** (`metaCognition.js` - 1,647 lines)
